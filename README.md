# House Price Prediction

Machine Learning project to predict house prices using Random Forest.

## Features

- FastAPI Backend
- HTML/CSS/JavaScript Frontend
- House Price Prediction
- REST API

## Run

Install packages

```bash
pip install -r requirements.txt
```

Run API

```bash
uvicorn app:app --reload
```

Open

```
http://127.0.0.1:8000/docs
```
